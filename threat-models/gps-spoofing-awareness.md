# Threat Model — GPS Spoofing and Interference Awareness

## Asset

Positioning, navigation, and timing data.

## Threat

GPS spoofing, jamming, or misleading location data.

## Why It Matters

Navigation and location awareness are safety-critical. Even when systems are not directly compromised, external signal manipulation can create operational risk.

## Potential Impacts

- Incorrect position awareness
- Navigation uncertainty
- Disrupted operations
- Increased crew workload

## Controls

- Cross-check navigation sources
- Train users to recognize anomalies
- Monitor notices/advisories
- Use layered navigation methods
- Document suspected interference events

## Note

This project is conceptual and defensive. It does not include instructions for spoofing, jamming, or interfering with navigation systems.
