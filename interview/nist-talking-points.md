# NIST Interview Talking Points

## 30-Second Version

I added NIST mapping so the project does more than list risks. It shows how aviation operational problems can be translated into recognized security controls. That matters in DoD-adjacent environments because teams need to communicate risk in a way engineers, operators, and compliance teams can all understand.

## Stronger Version

The project uses aviation maintenance experience as the domain layer, then maps each operational risk to a digital dependency, a likely cyber threat, an operational impact, a practical control, and a NIST alignment. For example, maintenance record tampering maps to access enforcement, logging, audit review, and information integrity because the real-world concern is a bad airworthiness decision.

## What Not To Say

Do not say this project makes you NIST compliant. Say it demonstrates framework-aware risk mapping.

## Best Phrase

"This project shows I can translate operational aviation risk into security controls and communicate that risk using NIST language."
