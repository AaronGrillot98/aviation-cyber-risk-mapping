# Aviation System Risk Map

## Purpose

Map aviation operational functions to digital systems, cyber threats, impacts, and controls.

| Aviation Function | Digital/System Dependency | Threat | Operational Impact | Control |
|---|---|---|---|---|
| Maintenance records | Maintenance tracking software | Record tampering | Bad airworthiness decision | Access control, audit logs, approvals |
| Parts tracking | Inventory/database system | Data integrity failure | Wrong part status or traceability issue | Change logs, role-based access |
| Flight scheduling | Scheduling platform | Account compromise | Incorrect schedule, readiness disruption | MFA, least privilege |
| Aircraft location tracking | GPS/ADS-B-related tools | Spoofing or false data | Situational awareness issue | Cross-check data sources |
| Ground network | Wi-Fi/admin network | Credential theft | Unauthorized access | Network segmentation, MFA |
| Technical documentation | Digital manuals | Outdated or altered data | Maintenance error | Version control, trusted sources |
| Work orders | Maintenance workflow tool | Unauthorized change | Missed corrective action | Approval workflow, audit trail |
| Training records | LMS/database | Record manipulation | Unqualified task assignment | Access reviews, logging |
| Vendor communication | Email/portal | Phishing | Credential compromise | Security awareness, email filtering |
| Mobile devices | Phones/tablets | Lost device or weak lock | Data exposure | MDM, encryption, passcodes |

## Key Lesson

Cyber risk in aviation is not only about aircraft hacking. It also includes the digital systems that support readiness, maintenance, logistics, documentation, and decision-making.
