# Aviation Cyber Risk Mapping Project

A portfolio project connecting aviation maintenance experience with cybersecurity risk analysis.

This project maps aviation operational areas to digital systems, cyber risks, possible impacts, and recommended controls.

## Why This Project Is Unique

Most cybersecurity beginners build generic labs. This project uses aviation domain knowledge as a security advantage.

It shows:

- Cyber risk thinking
- Aviation systems awareness
- Safety mindset
- Threat modeling
- Risk mapping
- Clear executive communication

## Core Idea

```text
Aviation operation → Digital system → Cyber risk → Operational impact → Recommended control
```

## Example

| Aviation Area | Digital System | Cyber Risk | Impact |
|---|---|---|---|
| Maintenance records | Digital maintenance tracking | Record tampering | Incorrect airworthiness decision |
| GPS/navigation | Positioning systems | Spoofing/interference | Navigation disruption |
| Parts tracking | Inventory database | Data integrity issue | Wrong part status or traceability gap |
| Ground network | Wi-Fi / admin systems | Credential compromise | Unauthorized system access |
