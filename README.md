# Aviation Cyber Risk Mapping Project

A portfolio project connecting aviation maintenance experience with cybersecurity risk analysis and NIST framework mapping.

This project maps aviation operational areas to digital systems, cyber risks, possible impacts, recommended controls, and NIST-aligned security concepts.

## Why This Project Is Unique

Most cybersecurity beginners build generic labs. This project uses aviation domain knowledge as a security advantage.

It shows:

- Cyber risk thinking
- Aviation systems awareness
- Safety mindset
- Threat modeling
- Risk mapping
- NIST framework awareness
- Clear executive communication

## Core Idea

```text
Aviation operation → Digital system → Cyber risk → Operational impact → Recommended control → NIST mapping
```

## Framework Alignment

This project uses:

- **NIST SP 800-53 Rev. 5** for control-level mapping.
- **NIST Cybersecurity Framework 2.0** for high-level risk communication.

This does **not** claim official compliance. It demonstrates the ability to translate aviation operational risk into recognized cybersecurity language.

## Example

| Aviation Area | Digital System | Cyber Risk | Impact | NIST Mapping |
|---|---|---|---|---|
| Maintenance records | Digital maintenance tracking | Record tampering | Incorrect airworthiness decision | AC-2, AC-3, AU-2, AU-6, SI-7 |
| GPS/navigation | Positioning systems | Spoofing/interference | Navigation disruption | SI-4, SI-7, AU-6 |
| Parts tracking | Inventory database | Data integrity issue | Wrong part status or traceability gap | AC-6, AU-2, AU-6, SI-7 |
| Ground network | Wi-Fi / admin systems | Credential compromise | Unauthorized system access | AC-17, IA-2, SC-7, AC-6 |
