# Start Here — Aviation Cyber Risk Mapping

## What You Are Building

You are building a cybersecurity risk-mapping project that connects aviation operations to cyber threats and controls.

## Best Order

1. Read `maps/aviation-system-risk-map.md`
2. Review each threat model
3. Fill out `templates/risk-entry-template.md`
4. Update the final report
5. Take screenshots for GitHub
6. Add your own aviation knowledge where appropriate

## Tools Needed

- GitHub
- Markdown editor
- Files app or Working Copy
- Optional: diagrams.net or draw.io for visual diagrams

No aircraft data, private technical manuals, or sensitive DoD information should be used.
