# Start Here — Aviation Cyber Risk Mapping

## What You Are Building

You are building a cybersecurity risk-mapping project that connects aviation operations to cyber threats, controls, and NIST framework alignment.

## Best Order

1. Read `maps/aviation-system-risk-map.md`
2. Read `docs/nist-mapping.md`
3. Review `controls/control-catalog.md`
4. Fill out `templates/risk-entry-template.md`
5. Update `reports/executive-summary.md` with your own wording
6. Take screenshots for GitHub
7. Practice the talking points in `interview/nist-talking-points.md`
8. Add your own aviation knowledge where appropriate

## Tools Needed

- GitHub
- Markdown editor
- Files app or Working Copy
- Optional: diagrams.net or draw.io for visual diagrams

No aircraft data, private technical manuals, real DoD information, credentials, or sensitive operational details should be used.
