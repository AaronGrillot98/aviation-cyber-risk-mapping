Aviation Cyber Risk Mapping Guide

Use your aviation maintenance background to build a unique cybersecurity portfolio project with NIST framework alignment.

What This Project Proves

This project proves you can connect operational systems to cyber risk, explain impact clearly, recommend controls, and map those controls to recognized frameworks.

Core Mapping Method

Aviation operation → Digital dependency → Threat → Impact → Control → NIST mapping

Frameworks Used

  • NIST SP 800-53 Rev. 5 for control-level mapping.
  • NIST Cybersecurity Framework 2.0 for high-level risk communication.

This is a portfolio demonstration, not an official compliance claim.
