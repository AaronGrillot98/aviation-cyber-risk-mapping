# Aviation Cyber Control Catalog

| Control Theme | Practical Control | Example Aviation Use | NIST Mapping |
|---|---|---|---|
| Account security | MFA and account reviews | Scheduling, LMS, maintenance systems | IA-2, AC-2 |
| Least privilege | Role-based access | Mechanics, supervisors, supply, admin staff | AC-6 |
| Auditability | Event logs and log review | Record changes, work orders, inventory updates | AU-2, AU-6 |
| Integrity | Change detection and trusted sources | Manuals, maintenance records, parts data | SI-7, CM-3 |
| Network protection | Segmentation and remote access control | Ground/admin networks | SC-7, AC-17 |
| Mobile protection | Passcodes, encryption, MDM | Tablets/phones used around maintenance ops | AC-19, SC-28 |
| Awareness | Phishing awareness and email filtering | Vendor portal and email risk | AT-2, SI-8 |
| Monitoring | Anomaly review and alerts | Spoofing, tampering, suspicious logins | SI-4, AU-6 |
